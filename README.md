# SQL-Server-Practice-Anushka
A company wants to develop an Employee Management System using SQL Server to manage its departments and employees.

The database should store department details and employee information, including Employee ID, Name, Email, Salary, Department ID, Joining Date, and Employment Status.

Perform the following operations:
1. Create a database named CompanyDB.
2. Create Departments and Employees tables using appropriate data types.
3. Apply constraints such as PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK, and DEFAULT.
4. Insert department and employee records.
5. Retrieve employee details along with their department names.
6. Update an employee's salary.
7. Delete an employee record.
8. Demonstrate the difference between DELETE and TRUNCATE.
9. Use transactions with BEGIN TRAN, COMMIT, and ROLLBACK.
10. Modify the Employees table by adding a new column.
11. Drop a temporary table.
